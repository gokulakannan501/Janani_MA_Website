# Janani Makeover Artistry Website

Professional portfolio and booking website for Janani Makeover Artistry.

## 🚀 Live Demo
[View Live Site on Vercel](https://janani-ma-website.vercel.app)

## 🚀 Getting Started

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Run the development server:**
   ```bash
   npm run dev
   ```

3. **Open [http://localhost:3000](http://localhost:3000) with your browser.**

## 🛠️ Tech Stack

- **Framework:** Next.js 15 (App Router)
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **Language:** TypeScript

## 📁 Project Structure

- `src/app`: Application routes (Home, About, Services, etc.)
- `src/components`: Reusable UI components
  - `ui`: Basic atoms (Button, Input)
  - `layout`: Navbar, Footer
  - `features`: Feature-specific components (ServiceCard, BookingForm, etc.)
- `src/data`: Mock data for development
- `src/types`: TypeScript interfaces
