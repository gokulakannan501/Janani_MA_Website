# Git Push Instructions

Run these commands in your terminal to push your code to GitHub:

```bash
cd scratch/makeover-artistry
git init
git add .
git commit -m "Initial commit: Complete Makeover Artistry Website with WhatsApp Booking"
git branch -M main
git remote add origin https://github.com/gokulakannan501/Janani_MA_Website
git push -u origin main
```
